# 壮壮FIT 门店备料助手

一个专为轻食门店设计的备料工具，帮助店员快速计算每日所需食材和调料用量。

## 功能

### 餐品备料助手
- 按品类（纤体Easy碗、蛋白pro碗、鲜蔬锅）逐道添加菜品
- 蛋白pro碗支持标准款/加肉款选择
- 自动选配餐（主食、酱汁、香蕉等）
- 点击菜品卡片可展开查看单份模块明细
- 一键生成备料清单，按模块汇总总量

### 调料计算助手
- 支持多种腌制配方：基础腌制、奥尔良腌制、地中海腌制、欧芹腌制、烤时蔬
- 输入食材实际重量，自动按比例换算调料用量
- 地中海/欧芹腌制自动合并基础配方

## 技术栈

- React 18
- Vite
- Tailwind CSS
- Lucide React (图标)

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

构建产物在 `dist/` 目录下，可直接部署到任意静态托管服务（Vercel、Netlify、GitHub Pages 等）。
